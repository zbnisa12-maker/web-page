# HTML Quiz — без JavaScript

Квиз из 10 вопросов по основам HTML. Для работы нужны только два файла: `index.html` и `style.css`.

## Как открыть

Скачай оба файла в одну папку и открой `index.html` в браузере. Установка, сервер, подключение к интернету и JavaScript не требуются.

## Как пользоваться

1. Выбери один ответ на каждый вопрос.
2. Внизу включи **Check my answers**.
3. Увидишь балл из 10, количество отвеченных вопросов и пояснения. Правильные варианты выделяются зелёным, выбранные ошибочные — красным.
4. Можно изменить ответ: результат обновится. Пропущенные вопросы дают 0 баллов.
5. **Start again** сбрасывает форму, ответы и показ результатов.

С клавиатуры: Tab переключает фокус, стрелки выбирают вариант внутри вопроса, Space включает проверку.

## Как это работает

- HTML-радиокнопки с одинаковым `name` позволяют выбрать один ответ на вопрос.
- У правильной радиокнопки указан `class="correct"`.
- CSS-селектор `:checked` увеличивает счётчики выбранных и правильных ответов. `counter()` выводит балл.
- `:has()` показывает результаты, подсветку и пояснения после включения флажка.
- Кнопка `type="reset"` использует встроенный сброс HTML-формы.

Нужен современный браузер с поддержкой CSS `:has()`. Подсчёт служит для самопроверки: правильные ответы видны в исходном HTML. Сохранения результатов и отправки на сервер нет. Числа счётчиков формируются через CSS; для проверки с программой чтения экрана также доступны текстовые пояснения к каждому вопросу.

## Что редактировать

- `index.html` — вопросы, варианты ответов и пояснения.
- `style.css` — цвета в `:root`, отступы, оформление и правила проверки.

При смене правильного варианта перенеси `class="correct"` на нужный `input` и обнови текст пояснения. Если добавляешь или удаляешь вопросы, обнови число вопросов, знаменатель балла и навигацию.
