# Web Page

Два готовых варианта сайта TagLab для изучения HTML.

| Проект | Описание |
| --- | --- |
| [taglab](./taglab/) | Полная версия: 11 страниц, анимации, 6 уроков, редактор HTML, практика, квиз и сохранение прогресса. |
| [taglab-simple](./taglab-simple/) | Упрощённая версия: 5 страниц, HTML, CSS и небольшой JavaScript для заданий и теста. |

## Как открыть

1. Нажми **Code → Download ZIP** и распакуй архив.
2. Открой папку нужного проекта.
3. Открой `index.html` в браузере. Оставь остальные файлы в той же папке.

Чтобы редактировать код, открой выбранную папку в VS Code. Подробные инструкции находятся в README каждого проекта.
